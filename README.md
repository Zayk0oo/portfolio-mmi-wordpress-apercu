# Nolhan Lambert · Portfolio MMI

Version de présentation du portfolio réalisé pour un travail WordPress.

## Publication sur GitHub Pages

Les fichiers de ce dossier doivent être placés à la racine d’un dépôt public. Dans Settings → Pages, sélectionner Deploy from a branch, puis main et / (root).

Cette version contient les pages, images, CV, logo et animations. Elle est statique : la version WordPress avec ses contenus modifiables est fournie séparément dans nolhan-portfolio.zip.
